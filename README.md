###  TradingView Buyside & Sellside Liquidity [MTF]

A professional multi-timeframe liquidity mapping indicator for TradingView, built for traders who trade institutional concepts such as CRT, SMT and liquidity engineering.

Features:
- Multi-timeframe liquidity levels — H1, H4, Daily, Weekly, Monthly, 3M, 12M
- Automatic TF visibility — levels shown adapt based on your current chart TF
- Time-based bar mapping — lines start exactly at the candle where liquidity 
  formed, not approximated
- Purged level detection — swept levels shown as dotted lines from formation 
  to sweep candle
- Hide purged toggle — clean chart mode shows only live unmitigated levels
- Label at right end of each level — clearly named BuySideLiquidity_D etc
- Live dashboard — bottom right table showing nearest BSL and SSL per TF
- Full color and width customization in settings
